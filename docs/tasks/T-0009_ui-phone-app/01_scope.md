# Scope

**Drin:**
- Tastenfeld: Status-Karte (Glas), Vorschlag beim Tippen, Hinweis auf neue verpasste Anrufe
- Anrufe: Info-Button mit Detail-Sheet, Kontaktfotos, Leer-Zustände mit Aktion, Tab-Badge
- Kontakte: Favoriten (lokal gespeichert) als Kacheln, Fotos, Favorit per Kontextmenü
- Einstellungen: Übersichtskarte oben
- Anruf-Screen: großes Foto, unscharfer Foto-Hintergrund bzw. Verlauf in der Farbe des Anrufers
- Gemeinsame Bausteine: farbige Avatare, App-Hintergrund, neue Leer-Zustände
- String-Kataloge im Xcode-Format (eigener Commit)

**Nicht drin:** Watch-App, Onboarding, neue Anruffunktionen (Halten, Konferenz), Kontaktposter in der App (keine öffentliche API, siehe Umsetzungsbericht).
