# Randbedingungen

- Kein Simulator, keine lokalen Xcode-Builds (M1, 8 GB): gebaut wird nur in der CI.
- Keine echten Nummern oder Namen in Code, Previews oder Tests.
- Design-Language: eine Akzentfarbe; Kontextfarben nur als Identität (Avatare); Verläufe nur ambient (8–20 %).
- Xcode-Projekt mit synchronisierten Ordnern: neue Dateien ohne Änderung an `project.pbxproj`.
- Xcode schreibt die String-Kataloge in seinem eigenen Format; Änderungen werden in genau diesem Format geschrieben.
