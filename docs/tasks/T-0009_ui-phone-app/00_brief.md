# T-0009 · Oberfläche näher an Apples Telefon-App (#31)

Die App wirkt auf allen Tabs leer. Ziel: so wie Apples Telefon-App (iOS 26), in der eigenen Design-Language, mit Liquid Glass.

Entscheidungen des Users: alle vier Richtungen – Favoriten & Vorschläge, Status-Karte, gestaltete Leer-Zustände, mehr Farbe & Tiefe. Bildschirme: Tastenfeld, Anrufe, Kontakte, Einstellungen, Anruf-Screen. Kontaktposter, wenn iOS das zulässt.
