# T-0017 Systemintegration: CarPlay, Widgets, Siri, Watch

Vorgabe (2026-10-08): „das volle Programm“, also alles, was eine gut und vollständig ins System eingebundene iPhone-App hat: CarPlay, Apple Watch, Widgets und so weiter.

Stand: CallKit zeigt Anrufe bereits in der CarPlay-Anrufoberfläche, in der Telefon-App-Anrufliste und auf der Watch. Rückruf aus der Anrufliste (`INStartCallIntent` als User Activity) funktioniert. Es fehlen eine gemeinsame Datenablage für Erweiterungen (App Group), Siri-Anrufe per Sprache, App Intents/Kurzbefehle, Widgets, Kontrollzentrum-Schalter, eine eigene CarPlay-Oberfläche und Watch-Komplikationen.
